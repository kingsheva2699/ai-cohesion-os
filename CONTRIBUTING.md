# Contributing

Contributions are welcome, especially from people using AI tools across messy real projects.

## Good first contributions

- Improve templates
- Add scanner logic
- Add examples with synthetic data
- Improve docs
- Add tests for scripts
- Add project graph/export formats

## Privacy rule

Do not submit real private workspace data, real client data, credentials, personal messages, or proprietary company material.

Use synthetic examples only.

## Development

```bash
python scripts/init_workspace.py ./tmp-workspace
python scripts/weekly_report.py ./tmp-workspace
```
