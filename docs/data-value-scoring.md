# Data Value Scoring

A piece of information is worth preserving when it changes future action or decision quality.

Score each dimension 0–10:

| Dimension | Weight |
|---|---:|
| Actionability | 20 |
| Decision impact | 15 |
| Durability | 15 |
| Confidence | 15 |
| Project relevance | 15 |
| Risk reduction | 10 |
| Leverage/reusability | 10 |

## Bands

- 85–100: Critical — preserve/update immediately.
- 70–84: High — preserve in project memory.
- 50–69: Medium — keep if tied to active work.
- 30–49: Low — avoid clutter.
- 0–29: Noise — ignore.

## Negative filters

Lower score if information is unsupported, stale, duplicated, private without operational use, generic, or likely to trigger unsafe action.
