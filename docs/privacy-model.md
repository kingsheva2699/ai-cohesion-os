# Privacy Model

Project Memory OS should be safe for private workspaces.

## Defaults

- Local-first.
- File-based.
- No telemetry by default.
- No external sends.
- No cloud sync unless explicitly configured.
- Users own their data.

## AI safety boundary

AI can:

- summarize;
- classify;
- suggest;
- draft;
- flag stale items.

AI should not automatically:

- send messages;
- delete files;
- publish externally;
- change billing/account settings;
- make legal/financial/medical claims.

## Public repo rule

Ship fake demo data only. Never include real user/client/project data.
