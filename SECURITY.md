# Security Policy

## Private data warning

Project Memory / AI Cohesion systems can touch sensitive project context. Do not commit private workspaces, credentials, personal chat exports, client records, or secrets.

## Reporting issues

If you find a privacy or security issue, open a GitHub security advisory if available or contact the maintainer privately.

## Defaults

This project is intended to be local-first. It should not send data to external services unless a user explicitly configures that behavior.
